# Lab 01 - Drive event planning with Microsoft 365 Copilot Chat

## Objective

You are an event planning consultant with Contoso Shoppee — a global consumer goods distributor. They are planning to host a high-impact Client Innovation Summit to showcase upcoming digital solutions, foster customer loyalty, and gather strategic input from key clients.

In this lab you will use Microsoft 365 Copilot Chat in Web Mode to:
-	Research market trends
-	Brainstorm summit sessions
-	Create visuals and documentation
-	Draft a planning brief
-	Upload and refine documents collaboratively.
